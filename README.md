# Tiny Realtor

*(Nombre provisional.)* Un juego idle de inmobiliaria que vive en una ventanita de 600x600 siempre encima del escritorio: abres oficinas inmobiliarias en barrios reales del mundo, compras edificios y solares a su alrededor, cobras alquileres y construyes hasta tener rascacielos. Los mapas son datos reales de OpenStreetMap (© OpenStreetMap contributors) dibujados en pixel art isométrico. Ahora mismo es solo el esqueleto: enseña una zona de muestra del Eixample. El diseño está en [`docs/DESIGN.md`](docs/DESIGN.md).

**Cómo abrirlo:** instala [Godot 4.7.1](https://godotengine.org/download/archive/4.7.1-stable/) (versión estándar, no .NET), abre Godot, pulsa *Importar*, elige el fichero `project.godot` de esta carpeta y dale a *Ejecutar* (F5). En la ventana: botón derecho y arrastrar para mover el mapa, botón izquierdo y arrastrar para mover la ventana, Esc para cerrar.
