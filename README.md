# Tiny Realtor

*(Nombre provisional.)* Un juego idle de inmobiliaria que vive en una ventanita de 600x600 siempre encima del escritorio: abres oficinas inmobiliarias en barrios reales del mundo, compras solares en sus calles, cobras alquileres y construyes hasta tener rascacielos. Los mapas son datos reales de OpenStreetMap (© OpenStreetMap contributors) dibujados en pixel art isométrico: de ellos salen las calles con sus nombres, los parques y el agua; las manzanas y parcelas las calcula el juego. Ahora mismo es el prototipo del mapa: eliges ciudad, ves su plano, pones una oficina y se descarga (una sola vez) su zona. El diseño está en [`docs/DESIGN.md`](docs/DESIGN.md).

**Cómo abrirlo:** instala [Godot 4.7.1](https://godotengine.org/download/archive/4.7.1-stable/) (versión estándar, no .NET), abre Godot, pulsa *Importar*, elige el fichero `project.godot` de esta carpeta y dale a *Ejecutar* (F5). En la ventana: arrastra la barra de arriba para mover la ventana; en los mapas, arrastra para moverte, rueda o botones - + para el zoom; clic para elegir sitio y "Abrir oficina" para confirmar; Esc para volver atrás (y cerrar desde la lista de ciudades). Para probar sin internet: `godot --path . -- --fixture` (datos inventados, salen marcados como DATOS DE PRUEBA). Para comprobar que las descargas reales funcionan en tu PC: `godot --headless --path . --script res://tools/net_check.gd`.
